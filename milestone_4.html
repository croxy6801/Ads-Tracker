1.2 Security Architecture & API Key Management

  • Envelope Encryption: Ad network access tokens and credentials are encrypted using AES-256-GCM. Decryption keys reside exclusively in secure environment variables or AWS KMS / HashiCorp Vault.
  • Strict Read-Only Enforcement: Integration adapters block write methods at the code level. The application does not instantiate mutation clients for Google Ads or Meta.
  • Zero Credential Logging: Logs automatically scrub sensitive patterns, authorization headers, and token signatures using masking filters.

4. Bug Fixes & Algorithm Precision Refinements

Rigorous integration testing surfaced edge cases that were resolved and verified:

  1. Calendar Date Engine Rollover: Resolved synthetic counter issues (e.g. "Nov 31", "Nov 70") by implementing a native JavaScript / Python calendar engine anchored to November 1, 2026. Dates roll seamlessly across month boundaries (Nov 30 → Dec 1 → Jan 1).
  2. Day 0 Zero-Baseline Calibration: Corrected simulator state initialization so that all metric cards (Today's Spend, Total Mature Spend, Blended CPA, Estimated Waste) and chart series start cleanly at ₹0 on Day 0, gradually accumulating as days advance.
  3. Maturity Window Fencepost Precision: Fixed a boundary off-by-one condition where Day 4 metrics were occasionally marked immature. The 72-hour window now strictly demarcates $t \le t_{\text{current}} - 3$.
  4. Header De-Cluttering & Brand Standards: Eliminated distracting decorative badges ("Financial Ad Auditor", "Maturity Shield", "25% Shift Protocol") and removed the green pulse dot from the header logo, cementing the clean Ads Tracker identity.
